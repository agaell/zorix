# Plugin Loader

`modules/plugin_loader` содержит минимальный механизм загрузки адаптеров Zorix.

Загрузчик не зависит от внешних пакетов и использует только стандартную библиотеку Python. Для импорта применяется `importlib`.

## Назначение

`PluginLoader` загружает адаптеры из указанного каталога.

Адаптер должен быть обычным Python-пакетом с `__init__.py`. Через `__init__.py` пакет должен экспортировать класс `Adapter` или `MockAdapter`.

Загрузчик выполняет четыре действия:

1. Находит пакеты адаптеров в указанном каталоге.
2. Импортирует каждый найденный пакет.
3. Проверяет, что экспортированный класс наследуется от контракта `Adapter` из `core_model`.
4. Создает экземпляр адаптера и возвращает список загруженных адаптеров.

## Границы

`core_model` не зависит от `plugin_loader`.

`core_model` не зависит от конкретных адаптеров.

`plugin_loader` зависит от контракта `Adapter`, потому что должен проверять корректность загружаемых классов.

Загрузчик не выполняет команды и не обращается к внешним системам. Он только импортирует Python-пакеты и создает экземпляры классов, соответствующих контракту.

## Обработка ошибок

Если пакет не импортируется, загрузчик сообщает об ошибке импорта.

Если пакет экспортирует `Adapter` или `MockAdapter`, но этот класс не наследуется от контракта `Adapter`, загрузчик отклоняет такой пакет.

Если один и тот же класс экспортирован под несколькими именами, загрузчик создает только один экземпляр.
